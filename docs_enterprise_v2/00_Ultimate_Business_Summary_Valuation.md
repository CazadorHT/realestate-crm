## 🛡️ 4. ความปลอดภัย (Security & Privacy) - **Bank-Grade**

*   **Hardened RLS**: ข้อมูลถูกแยกสาขา (Tenant Isolation) ในระดับ Database ชั้นลึกที่สุด ข้อมูลไม่มีวันรั่วไหลข้ามสาขา 100%
*   **Native Proxy**: ระบบดักจับคำสั่งเพื่อยืนยันสิทธิ์ทุกครั้ง ป้องกัน Human Error จากโปรแกรมเมอร์
*   **AES-256 Encryption**: ข้อมูลสำคัญ (เช่น API Tokens) ถูกเข้ารหัสก่อนลงฐานข้อมูล
*   **Audit Timeline**: บันทึกทุกรอยนิ้วมือการแก้ไข (Field-level logs) พร้อมปุ่มกู้คืนข้อมูล (Restore)
