## 🛠 3. เครื่องมือและสถาปัตยกรรม (Tech Stack & Architecture)

*   **Frontend:** Next.js 16.2 (Turbopack) + React 19 + Tailwind CSS (สถาปัตยกรรม App Router ที่เร็วที่สุด)
*   **Architecture Pattern:** **Permanent CQRS** (แยก Direct Core Write ออกจาก View Bridge Read พร้อม Surgical Precision Indexes)
*   **Spatial & Map Engine:** MapLibre GL + **PostGIS** + **Uber H3 Spatial Index (Resolution 8)**
*   **Vector Database:** 1536-dimensional Vector Embeddings สำหรับ AI Smart Match และ Semantic Search
*   **Backend & DB Vault:** Supabase Enterprise (PostgreSQL + Atomic RPC + `identity_secrets` PDPA Vault)
*   **Background Orchestration:** Inngest (Event-Driven Background Resilience & Weekly Auto-Partitioning)
*   **Edge & Security:** Upstash Redis (Speed & Rate Limiting) + Sharp Engine (High-Performance Image Processing)

## 🛡️ 4. ความปลอดภัย (Security & Privacy) - **Bank-Grade**

*   **Hardened RLS & Isolated Demo:** ข้อมูลถูกแยกสาขา (Tenant Isolation) ในระดับ Database ลึกที่สุด และมี **Isolated Sandbox Demo Tenant** สำหรับฝ่ายขายใช้เดโม่โดยไม่เสี่ยงข้อมูลจริง
*   **Native Proxy Guard:** ระบบดักจับคำสั่งเพื่อยืนยันสิทธิ์ทุกครั้ง ป้องกัน Human Error จากโปรแกรมเมอร์
*   **PDPA Database Vault (AES-256):** ข้อมูลอ่อนไหว (บัตรประชาชน, พาสปอร์ต, บัญชีธนาคาร) ถูกแยกเก็บและเข้ารหัสอย่างเข้มงวด
*   **Audit Timeline & Partitioning:** บันทึกทุกรอยนิ้วมือการแก้ไข (Field-level logs) แยกตารางรายเดือน พร้อมปุ่มกู้คืนข้อมูล (Restore)
