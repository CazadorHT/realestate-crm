# 📘 08: คู่มือผู้ดูแลระบบและแอดมินสาขา (Enterprise User & Admin Manual)

> **สำหรับ:** ผู้จัดการสาขา (Branch Manager) และพนักงานระดับปฏิบัติการ
> **จุดประสงค์:** การใช้งานฟีเจอร์ขั้นสูงอย่างฉลาดและไม่ทำลายระเบียบข้อมูลบริษัท

ซอฟต์แวร์ที่เราสร้างนี้ เป็นมากกกว่าระบบกรอกข้อมูล ให้อารมณ์เหมือนหน้าปัดเครื่องบินรบ (Cockpit) ที่มีปุ่มทำลายตัวเองและปุ่มกู้ชีวิต นี่คือคู่มือหลักสเต็ปสำคัญ

---

## 1. กระบวนการ "ย้อนเวลาหาอดีต" (Visual Diff Audit Timeline)

ไม่ต้องตกใจเวลาพนักงานใหม่กดมือลั่นลบข้อมูลราคาสัญญา

### วิธีใช้งาน 
1. เข้าไปที่แถบ **[ประวัติบริษัท]** (Audit Logs Segment)
2. ระบบจะดึงตารางกึ่งๆ โชว์สเตตัสสีบอกบรรทัด สีแดงคือ "ของเก่าที่หาย" สีเขียวคือ "ของใหม่ที่ถูกเติมเข้ามา" ให้เหมือนวิศวกรอ่านโค้ด
3. หากคุณพบว่ามีการทุจริตแก้คอมมิชชัน หรือแก้ราคาบ้านพิมพ์ 0 ตกไปหนึ่งตัว ให้กดปุ่ม **"ดึงข้อมูลกลับ (Restore Version)"**
4. ระบบจะทำการล้างข้อมูลชุดล่าสุดทิ้ง แล้วสูบข้อมูลฉบับที่จำศึลอยู่ใน JSONB กลับเข้าตารางแบบไม่มีรอยต่อ

---

## 2. ควบคุมหุ่นยนต์ลูกจ้าง (Sentinel AI Workflow)

AI ทุกตัวในระบบนี้ ถูกใส่ปลอกคอไว้แล้ว

### วิธีดำเนินการตรวจทาน (Approve)
1. พนักงานระดับล่าง สั่งโปรแกรม AI ให้แต่งคำบรรยายภาพบ้าน ระบบจะพ่นข้อมูลเสร็จ แต่อยู่ในหมวด "ฉบับร่าง (Pending Publish)"
2. ผู้ที่มีสิทธิ์เป็น **[Sentinel]** (มักจะเป็นคุณ) ต้องไปที่เมนู **กักตรวจคอนเทนต์**
3. อ่านทบทวนบรรทัดต่อบรรทัด หาก AI เขียนผิด คุณสามารถแก้ไขได้ตรงอิดิเตอร์ (TipTap) 
4. กด Approve เพื่อปล่อยยานข้อมูลออกสู่อินเทอร์เน็ต (Public)
5. **ข้อควรระวัง:** การกดให้ AI แต่งประโยค ทุุกคลิกจะมีค่าใช้จ่าย สามารถถูกตามเช็คสถิติ (Token Burn Rate) ได้ใน Dashboard

## 3. ประสบการณ์มือถืออัจฉริยะ (Mobile-First Drawers)

หากคุณถือมือถือหน้าไซต์งาน (เดินเช็คพาดูคอนโด):
- คุณจะไม่เจอป็อปอัพเหลี่ยมๆ เด้งมาตัดหน้ากะทันหันแบบคอมพิวเตอร์
- โปรเจคเราใส่ระบบ **Drawer (ลิ้นชักล่าง)** เวลาเพิ่มบ้าน หรือหาฟิลเตอร์ค้นหา ให้คุณใช้นิ้วโป้งเกี่ยวหน้าจอ ลากขึ้นเพื่อดูข้อมูล แล้ว "ปัดทิ้งลงข้างล่าง" เพื่อปิดลิ้นชักได้เหมือนแอป Native ขนานแท้

## 4. ห้องควบคุมงานเบื้องหลัง (Unified Process Monitor)

ในระบบนี้ งานที่ต้องใช้เวลา (เช่น การอัปโหลดรูปภาพจำนวนมาก หรือการใช้ AI วิเคราะห์ข้อมูล) จะไม่ทำให้คุณต้องนั่งรอหน้าจอนิ่งๆ อีกต่อไป

### วิธีใช้งานห้องควบคุม
1. **สังเกตปุ่มวงกลมอัจฉริยะ**: ที่มุมขวาล่างของหน้าจอ จะมีปุ่มวงกลมลอยอยู่ (Floating Monitor) หากมีงานกำลังรันอยู่ ปุ่มจะแสดงตัวเลขจำนวนงานที่กำลังทำ (Processing)
2. **เปิดดูรายละเอียด**: คลิกที่ปุ่มเพื่อเปิด "ห้องควบคุม" คุณจะเห็นรายการงานทั้งหมดที่ระบบกำลังทำอยู่แบบวินาทีต่อวินาที
   - **Progress Update**: เช่น "อัปโหลดสำเร็จแล้ว 4/10 รูป" หรือ "AI กำลังร่างคำบรรยาย..."
   - **Status Check**: หากงานไหนสำเร็จจะมีเครื่องหมายถูกสีเขียว หากล้มเหลวจะเป็นเครื่องหมายตกใจสีแดง
3. **การแก้ไขปัญหา (Retry)**: หากงานล้มเหลว (เช่น อินเทอร์เน็ตหลุดระหว่างส่งไลน์) คุณสามารถกดปุ่ม **"ลองอีกครั้ง (Retry)"** ได้จากในหน้าจอนี้ทันทีโดยไม่ต้องไปเริ่มกดสั่งงานใหม่ในหน้าเดิม
4. **ความคล่องตัว (Multitasking)**: คุณสามารถสั่ง AI แปลภาษาบทความทิ้งไว้ แล้วสลับหน้าจอไปดูยอดขายใน Dashboard ได้เลย ระบบจะคอยรายงานความคืบหน้าผ่านปุ่มวงกลมนี้ตลอดเวลา

## 5. การใช้งานเครื่องมือสร้างการ์ดโฆษณา (Social Studio)

การ์ดโฆษณาสำหรับส่งออกโซเชียลมีเดียสามารถปรับแต่งได้ในหน้าบริหารจัดการอสังหาฯ:

### ขั้นตอนการใช้งาน
1. **เลือกทรัพย์สิน** ที่ต้องการทำสื่อการตลาด แล้วคลิกปุ่ม **[Social Studio]**
2. **เลือกอัตราส่วนการ์ด (Aspect Ratio)**:
   - `1:1` สำหรับโพสต์ Facebook / Instagram Feed
   - `4:5` สำหรับ Instagram Portrait
   - `9:16` สำหรับ LINE / TikTok / Instagram Story
3. **ปรับแต่งข้อมูลและการแสดงผล**:
   - ปรับราคา, จุดเด่น (Selling Points), และธีมสีของการ์ด
   - เลือกแท็บพรีวิว platform (LINE, Facebook, IG, TikTok) เพื่อดูการแสดงผลเสมือนจริง
4. **ส่งออกสื่อการตลาด**:
   - กด **[ดาวน์โหลดรูปภาพ]** หรือกด **[แชร์ออกแพลตฟอร์ม]** เพื่อส่งรูปไปยังช่องทางโซเชียลมีเดียที่เชื่อมต่อไว้

## 6. การจัดการทำเลทองและพื้นที่ยอดนิยม (Popular Areas Admin)

แอดมินสามารถจัดการรายชื่อทำเลทองเพื่อนำไปใช้แนะนำในช่องค้นหา `MagicAiSearch`:

### ขั้นตอนการตั้งค่า
1. เข้าไปที่เมนู **[ตั้งค่าระบบ]** > **[พื้นที่ยอดนิยม (Popular Areas)]**
2. กด **[เพิ่มทำเลใหม่]** ระบุชื่อพื้นที่ (เช่น สุขุมวิท, อารีย์, พระราม 9) พร้อมละติจูด/ลองจิจูด และรูปภาพปก
3. กำหนดลำดับการแสดงผล (Display Order) และสถานะเปิด/ปิดการใช้งาน
4. เมื่อบันทึกสำเร็จ ข้อมูลพื้นที่ยอดนิยมจะถูกดึงไปแสดงผลในหน้าค้นหาฝั่งผู้ใช้งานโดยอัตโนมัติ

---

## 7. การตรวจสอบข้อมูลฝากขาย/ฝากเช่า (Public Deposit Leads)

ฟอร์มรับฝากขาย/ฝากเช่าจากหน้าเว็บสาธารณะ มีระบบคัดกรองสแปมและ Bot อัตโนมัติ:

### ขั้นตอนการจัดการข้อมูล
1. เข้าไปที่เมนู **[Leads]** > **[รายการฝากขายสาธารณะ]**
2. รายการส่งฟอร์มที่ผ่านการตรวจสอบ Honeypot และ Rate Limit จะปรากฏในตารางพร้อมป้ายกำกับสถานะ
3. คลิกดูรายละเอียดเพื่อตรวจสอบข้อมูลผู้ฝาก, รูปภาพที่อัปโหลดเข้ามา, และรายละเอียดทรัพย์สิน
4. กด **[อนุมัติเป็น Listing]** เพื่อนำเข้าสู่ระบบจัดการทรัพย์สิน หรือกด **[ปฏิเสธ]** ในกรณีข้อมูลไม่ถูกต้อง
