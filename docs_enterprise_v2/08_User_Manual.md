# 📘 08: คู่มือผู้ดูแลระบบและแอดมินสาขา (Enterprise User & Admin Manual)

> **สำหรับ:** ผู้จัดการสาขา (Branch Manager) และพนักงานระดับปฏิบัติการ
> **จุดประสงค์:** การใช้งานฟีเจอร์ขั้นสูงอย่างฉลาดและไม่ทำลายระเบียบข้อมูลบริษัท

ซอฟต์แวร์ที่เราสร้างนี้ เป็นมากกกว่าระบบกรอกข้อมูล ให้อารมณ์เหมือนหน้าปัดเครื่องบินรบ (Cockpit) ที่มีปุ่มทำลายตัวเองและปุ่มกู้ชีวิต นี่คือคู่มือหลักสเต็ปสำคัญ

---

## 1. กระบวนการ "ย้อนเวลาหาอดีต" (Visual Diff Audit Timeline)

ไม่ต้องตกใจเวลาพนักงานใหม่กดมือลั่นลบข้อมูลราคาสัญญา

### วิธีใช้งาน 
1. เข้าไปที่แถบ **[ประวัติบริษัท]** (Audit Logs Segment)
2. ระบบจะดึงตารางกึ่งๆ โชว์สเตตัสสีบอกบรรทัด สีแดงคือ "ของเก่าที่หาย" สีเขียวคือ "ของใหม่ที่ถูกเติมเข้ามา" ให้เหมือนวิศวกรอ่านโค้ด
3. หากคุณพบว่ามีการทุจริตแก้คอมมิชชัน หรือแก้ราคาบ้านพิมพ์ 0 ตกไปหนึ่งตัว ให้กดปุ่ม **"ดึงข้อมูลกลับ (Restore Version)"**
4. ระบบจะทำการล้างข้อมูลชุดล่าสุดทิ้ง แล้วสูบข้อมูลฉบับที่จำศึลอยู่ใน JSONB กลับเข้าตารางแบบไม่มีรอยต่อ

## 2. ควบคุมหุ่นยนต์ลูกจ้าง (Sentinel AI Workflow)

AI ทุกตัวในระบบนี้ ถูกใส่ปลอกคอไว้แล้ว

### วิธีดำเนินการตรวจทาน (Approve)
1. พนักงานระดับล่าง สั่งโปรแกรม AI ให้แต่งคำบรรยายภาพบ้าน ระบบจะพ่นข้อมูลเสร็จ แต่อยู่ในหมวด "ฉบับร่าง (Pending Publish)"
2. ผู้ที่มีสิทธิ์เป็น **[Sentinel]** (มักจะเป็นคุณ) ต้องไปที่เมนู **กักตรวจคอนเทนต์**
3. อ่านทบทวนบรรทัดต่อบรรทัด หาก AI เขียนผิด คุณสามารถแก้ไขได้ตรงอิดิเตอร์ (TipTap) 
4. กด Approve เพื่อปล่อยยานข้อมูลออกสู่อินเทอร์เน็ต (Public)
5. **ข้อควรระวัง:** การกดให้ AI แต่งประโยค ทุุกคลิกจะมีค่าใช้จ่าย สามารถถูกตามเช็คสถิติ (Token Burn Rate) ได้ใน Dashboard

## 3. ประสบการณ์มือถืออัจฉริยะ (Mobile-First Drawers)

หากคุณถือมือถือหน้าไซต์งาน (เดินเช็คพาดูคอนโด):
- คุณจะไม่เจอป็อปอัพเหลี่ยมๆ เด้งมาตัดหน้ากะทันหันแบบคอมพิวเตอร์
- โปรเจคเราใส่ระบบ **Drawer (ลิ้นชักล่าง)** เวลาเพิ่มบ้าน หรือหาฟิลเตอร์ค้นหา ให้คุณใช้นิ้วโป้งเกี่ยวหน้าจอ ลากขึ้นเพื่อดูข้อมูล แล้ว "ปัดทิ้งลงข้างล่าง" เพื่อปิดลิ้นชักได้เหมือนแอป Native ขนานแท้
- ระบบสามารถกดสไลด์รูปแกลเลอรี และสแกน QR Code จากกล้องมือถือได้ลื่นไหล ไม่ต้องกลัวว่ากดอัปรูปแล้วรอโหลดนานจนเว็บระเบิด เพราะระบบแอบบีบอัดรูปก่อนกินอินเทอร์เน็ตของคุณ
