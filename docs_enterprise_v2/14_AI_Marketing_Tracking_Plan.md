# 🧠 14: โครงสร้างสมองกลประสานมนุษย์ (AI Sentinel & Token Economics)

> **แนวคิดหลัก:** Human-in-the-loop (Sentinel), Cost Arbitrage, GTM Tracking, Social Studio Integration
> **อัปเดตล่าสุด:** 22 สิงหาคม 2026 (Enterprise v4.0 - August 2026 Release)
> **เป้าหมาย:** ปิดฉากปัญหา AI หลอน และควบคุมงบประมาณค่าเช่าสมอง AI ขั้นเบ็ดเสร็จ

AI ในโลก Enterprise ไม่ใช่แค่ของวิเศษ แต่คือ "พนักงานจ้างเหมา" ที่ต้องมีการคุมความประพฤติ และตรวจสอบบิลค่าจ้างทุกสิ้นเดือน

## 1. กลไก The Sentinel (มนุษย์คือผู้คุมกฎ)

องค์กรขนาดใหญ่อาจโดนฟ้องล้มละลายได้ หาก AI ที่ทำหน้าที่เขียนคำบรรยายบ้าน (Description Generator) เผลอสร้างข้อความสัญญาสมมติ หรือให้ราคาคอนโดผิดจาก 5 ล้านเป็น 5 แสนบาท

### 1.1 Draft & Quarantine State (ด่านกักกัน)
- ปฏิเสธการ Auto-Publish 100%: ไม่ว่า AI จะเขียนบล็อกหรือสรุปราคาสะพรั่งแค่ไหน ทรัพย์จะถูกตีตราสถานะ `DRAFT_PENDING` เสมอ
- สาขาจะต้องมีพนักงานที่มีสิทธิ์ **[AI Sentinel Role]** เท่านั้น เข้ามาอ่านกะเทาะข้อความทีละบรรทัด (เหมือน บก. ข่าว) พอกด Approve แผนส่งหน้าเว็บ (Deployment) ก๊อกสองถึงจะวิ่งทำงาน 

### 1.2 "AI Hallucination" Fallback (ส้นเท้าเบรคสติ AI)
Prompt ทุกตัวในเซิร์ฟเวอร์ถูกฉีดคำสั่งสะกดจิตเข้มงวด เช่น "DO NOT INVENT AMENITIES" หาก AI หลอนพยายามเติมคำว่า "มีลานจอดคอปเตอร์" ทั้งที่ไม่ระบุ โค้ดหน้าบ้านเราจะข้ามและไม่เรนเดอร์คำประหลาดเหล่านั้น

## 2. Token Economics (ระบบมาร์จิ้นค่า AI)

ถ้าคุณปล่อยให้เซลล์ร้อยคนกดเจนบล็อกเล่นสนุกๆ วันละร้อยกระทู้ บิลรายเดือนจากฝั่ง Google/OpenAI จะทะลวงบริษัทกระเป๋าขาด

### 2.1 The Dashboard Exchange Rate
โค้ดมีระบบสอดส่องและเก็บสถิติลงตาราง `ai_usage_logs`
- แปลงสถิติค่านั้นกลับเป็น เงินบาทไทยแบบเรียลไทม์ (จำลอง 32 THB = 1 USD) โชว์หราอยู่บน Dashboard แอดมิน ให้เห็นว่าวันนี้เซลล์ A ละลายเงินค่าโทเค็นบริษัทไปกี่บาท
- **Arbitrage Billing:** ฝั่งองค์กร(แบรนด์แม่) สามารถเซ็ตบิลแพ็กเกจขายแอดออนให้ลูกแฟรนไชส์ได้ (เช่น "แพ็ก 500 บาทรันได้ 200 โพสต์") สร้างกำไรส่วนต่างให้กับเจ้าของแพลตฟอร์มแบบน้ำซึมบ่อทราย

### 2.2 Google Tag Manager (GTM) Converging Pipeline
ทุกครั้งที่ User อ่านโพสต์ที่ AI แต่งเสร็จ แล้วกดเลื่อนดูรูปคอนโด หรือก๊อปลิงก์ LINE 
- โค้ดฝั่ง Client จะชู้ต Data Layer ข้ามไป GTM อัตโนมัติ (เช่น `event: property_viewed_deep`) ส่งให้เอเจนซี่ยิง Ads Retargeting ต่อได้อย่างแม่นยำ

## 3. Social Studio AI Copywriting Generator (`components/social-studio`)

ขยายขีดความสามารถ AI สมองกลในเวอร์ชัน 4.0 เข้าสู่ **Social Studio**:
- **Multi-lingual Caption Generation**: สร้างคำบรรยายโปรโมตอสังหาริมทรัพย์ภาษาไทย อังกฤษ และจีน พร้อมแฮชแท็กติดเทรนด์สำหรับการแชร์บน LINE, Facebook, และ TikTok
- **Template-Aware Layout Intelligence**: คำนวณความยาวข้อความให้อยู่ในสัดส่วนพอดีกับกรอบดีไซน์การ์ดโฆษณา (1:1, 4:5, 9:16) ไม่ให้ตัวหนังสือหลุดขอบการ์ด
