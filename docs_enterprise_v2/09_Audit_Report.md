# 🕵️ 09: ระบบตรวจสอบประวัติและลบรหัสวิกฤต (Audit Tracking & Property Timeline)

> **โครงสร้างหลัก:** PostgreSQL Table Partitioning, JSONB Snapshots, Property Audit Timeline
> **เป้าหมาย:** สร้างระบบการจดจำประวัติศาสตร์ที่ดัดแปลงไม่ได้ สเกลได้ร้อยล้านแถว และกู้คืนข้อมูลได้ทันที
> **เวอร์ชัน:** Enterprise v3.0 (Hardened)

การปล่อยให้พนักงานจำนวนมาก เข้ามาจัดการธุรกรรมและข้อมูลทรัพย์สินมูลค่ามหาศาล ย่อมเกิด Human Error ระบบในเวอร์ชัน 3.0 จึงยกระดับการตรวจสอบสู่ระดับสูงสุด

---

## 1. Property Audit Timeline (Visual Time-travel)

ในเวอร์ชันล่าสุด เราได้เพิ่มเลเยอร์การตรวจสอบระดับทรัพย์สิน (Field-level Auditing):

- **Visual Diffing**: เมื่อมีการแก้ไขข้อมูลทรัพย์สิน ระบบจะเก็บ Snapshot และแสดงผลในรูปแบบ Visual Diff (สีเขียว-แดง) ให้เห็นชัดเจนว่า "ใคร เปลี่ยนฟิลด์ไหน จากอะไร เป็นอะไร"
- **One-click Restore**: หากพบการแก้ไขที่ผิดพลาด ผู้บริหารสามารถกดปุ่ม "Restore" เพื่อย้อนข้อมูลทรัพย์สินกลับไปเป็นเวอร์ชันใดก็ได้ในอดีตทันที โดยระบบจะจัดการความสัมพันธ์ของข้อมูล (Relationships) ให้โดยอัตโนมัติ

---

## 2. Table Partitioning (ป้องกัน Audit บวมแตก)

บริษัทใหญ่ๆ มักเจอปัญหา Database ล่มสลายหลังจากใช้งานไป 2-3 ปี เพราะฐานข้อมูลตาราง Logs มีข้อมูลมหาศาลจนคำสั่ง Select ทำงานไม่ได้

### 2.1 กระบวนทัศน์การหั่นชิ้นเค้กรายเดือน
ตาราง `audit_logs` ของเราใช้เทคนิค **Table Partitioning แยกหั่นรายเดือน** ของ PostgreSQL:
- **High Performance**: การค้นหาประวัติย้อนหลังจะเจาะจงเฉพาะ Partition ของเดือนนั้นๆ ทำให้ความเร็วคงที่แม้จะมีข้อมูลหลายล้านแถว
- **Data Life Cycle (PDPA)**: สามารถลบข้อมูลเก่าทิ้งได้แบบยกตระกร้า (Drop Partition) ตามกฎหมาย PDPA โดยไม่กระทบต่อประสิทธิภาพของฐานข้อมูลหลัก

## 3. JSONB Snapshots & Integrity

ในทุกธุรกรรมที่สำคัญ ระบบจะปั๊มสิ่งที่เรียกว่า **Atomic Snapshot** ลงในฟิลด์ JSONB:
- **Immutable History**: ประวัติการแก้ไขถูกหุ้มด้วย RLS (Read-only for Agents) ทำให้พนักงานไม่สามารถเข้าไปลบประวัติการทำผิดของตัวเองได้
- **Integrity Check**: ระบบสามารถรัน Script เพื่อตรวจสอบความถูกต้องของข้อมูล (Integrity) ระหว่างตารางหลักและตาราง Audit ได้ตลอดเวลา เพื่อป้องกันการทุจริตภายในองค์กร

ระบบนี้เปรียบราวกับ "กล่องดำกู้ภัยของเครื่องบิน" ที่บันทึกทุกวินาทีของการเคลื่อนไหวในธุรกิจคุณ เพื่อความโปร่งใสสูงสุดระดับมหาชน!
