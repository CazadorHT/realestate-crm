# 🛠️ 20: สถาปัตยกรรมระดับสูง Dynamic RPC (Elite Architecture)

> **เทคโนโลยีหลัก:** PostgreSQL JSONB RPC, Dynamic Whitelisting, Transactional Integrity
> **เป้าหมาย:** ระบบอัปเดตข้อมูลที่ "ไร้รอยต่อ" และ "ปลอดภัยระดับสูงสุด" โดยไม่ต้องเขียน SQL ใหม่ทุกครั้งที่เพิ่มฟิลด์

คู่มือนี้อธิบายเบื้องหลังเทคโนโลยี **Atomic RPC** ที่เป็นหัวใจสำคัญของการจัดการข้อมูลในระบบ VC Connect Asset CRM ซึ่งถูกออกแบบมาให้เป็น **Schema-Agnostic** และ **Secure-by-Design**

---

## 🏗️ แนวคิดการทำงาน (The Elite Concept)

แทนที่เราจะส่งคำสั่ง SQL หลายๆ ครั้งจาก Client (ซึ่งเสี่ยงต่อการที่ข้อมูลบางส่วนล้มเหลวแต่บางส่วนสำเร็จ), ระบบเราใช้รูปแบบ **Single-Transaction RPC**:
1.  **JSON Payload**: ข้อมูลทั้งหมด (ข้อมูลหลัก + รูปภาพ + เอเจนท์) จะถูกรวมเป็นก้อน JSON เพียงก้อนเดียว
2.  **Atomic Transaction**: ข้อมูลจะถูกส่งไปยังฟังก์ชัน `update_property_elite` ในฐานข้อมูล ซึ่งจะทำการบันทึกข้อมูลทุกส่วนให้สำเร็จ "พร้อมกัน" หรือ "ล้มเหลวพร้อมกัน" 100% ป้องกันข้อมูลขยะค้างในระบบ

---

## 🚀 จุดเด่นด้านวิศวกรรม (Engineering Excellence)

### 1. Dynamic Mapping (Future-Proof)
ระบบจะทำการจับคู่ (Map) คีย์ใน JSON กับชื่อคอลัมน์ในตารางให้โดยอัตโนมัติ:
- **ไม่ต้องเขียน SQL ใหม่**: เมื่อคุณเพิ่มคอลัมน์ใหม่ในฐานข้อมูล ระบบจะรับรู้และอัปเดตฟิลด์นั้นให้ทันทีผ่าน Dynamic Whitelisting
- **ลดหนี้ทางเทคนิค**: ประหยัดเวลาการพัฒนาลง 90% เมื่อต้องมีการเปลี่ยนแปลงโครงสร้างข้อมูลในอนาคต

### 2. Optimistic Locking (Zero Lost Updates)
ป้องกันปัญหา "การเขียนทับข้อมูลโดยไม่ตั้งใจ" เมื่อมีพนักงานสองคนแก้ไขทรัพย์สินชิ้นเดียวกันพร้อมกัน:
- ระบบจะตรวจสอบ **Version Token** ก่อนการบันทึก หากพบว่าข้อมูลมีการเปลี่ยนแปลงไปก่อนหน้าแล้ว ระบบจะแจ้งเตือนให้โหลดข้อมูลใหม่ทันที

### 3. Strict Whitelisting (Security Layer)
ระบบมี **Internal Blacklist** ป้องกันการแก้ไขคอลัมน์สำคัญผ่านระบบ Dynamic:
- คอลัมน์เช่น `id`, `tenant_id`, `created_at` จะไม่สามารถถูกแก้ไขได้ผ่านทางนี้เด็ดขาด เพื่อรักษาความปลอดภัยของระบบ Multi-Tenant

## 🔍 การตรวจสอบและกู้คืน (Debugging & Recovery)

ระบบ RPC นี้ทำงานร่วมกับ **Audit Timeline** (ไฟล์ 09):
- ทุกการอัปเดตผ่าน RPC จะถูกบันทึกสภาพ "ก่อน" และ "หลัง" ไว้ในตาราง Audit ทันที
- ทำให้เราสามารถย้อนรอยความผิดพลาด (Traceability) และกู้คืนข้อมูล (Recovery) ได้ในระดับระดับอะตอม
