# 🔐 คู่มือการตั้งค่าความปลอดภัย Cron Job (CRON_SECRET)

เอกสารฉบับนี้อธิบายวิธีการตั้งค่ารหัสลับเพื่อป้องกันไม่ให้ผู้ไม่หวังดีรันงานอัตโนมัติ (Cron Job) ของระบบโดยไม่ได้รับอนุญาต

---

## 🛡️ ทำไมต้องตั้งค่า CRON_SECRET?
ในระบบใหม่ของเรา งานอัตโนมัติทั้งหมดถูกรวมไว้ที่ Endpoint เดียวคิอ `/api/cron/unified` หากไม่มีรหัสผ่าน ใครก็ตามที่ทราบ URL นี้จะสามารถสั่งให้ระบบรันงานซ้ำๆ ได้ ซึ่งอาจทำให้:
1.  **ส่งแจ้งเตือนซ้ำ:** ผู้เช่าอาจได้รับ LINE แจ้งเตือนค่าเช่าหลายรอบจนเกิดความรำคาญ
2.  **เปลืองทรัพยากร:** ระบบต้องคำนวณราคาตลาด (AVM) และดึงข้อมูลจำนวนมากทำให้ Server ทำงานหนัก
3.  **ความปลอดภัยข้อมูล:** แม้จะไม่สามารถขโมยข้อมูลได้โดยตรง แต่เป็นการเปิดช่องให้ทำ Denial of Service (DoS) ได้

---

## 🛠️ ขั้นตอนการติดตั้ง

### 1. สร้างรหัสลับ (Generate Secret)
แนะนำให้ใช้รหัสที่เดายากและมีความยาวพอสมควร คุณสามารถใช้คำสั่งนี้ใน Terminal เพื่อสร้างรหัสมาตรฐานสูง:
```bash
openssl rand -base64 32
```
*ตัวอย่างรหัสที่ได้:* `wX2y9+mK5nLp8Rz...`

### 2. ตั้งค่าใน Vercel Dashboard
เพื่อให้ Code บน Server รู้จักรหัสนี้ ต้องนำไปใส่ใน Environment Variables:
1.  เข้าสู่ [Vercel Dashboard](https://vercel.com/dashboard)
2.  เลือกโปรเจกต์ **realestate-crm**
3.  ไปที่แถบ **Settings** > **Environment Variables**
4.  เพิ่มตัวแปรใหม่:
    - **Key:** `CRON_SECRET`
    - **Value:** (วางรหัสที่สร้างจากข้อ 1)
5.  กด **Save** และทำการ **Redeploy** เพื่อให้ค่ามีผลใช้งาน

### 3. ตั้งค่าในเครื่องคอมพิวเตอร์ (Local Development)
สำหรับการทดสอบในเครื่องตัวเอง ให้เพิ่มรหัสเดียวกันลงในไฟล์ `.env` หรือ `.env.local`:
```env
CRON_SECRET=รหัสล็บของคุณที่นี่
```

---

## 🧪 การทดสอบความถูกต้อง
เมื่อตั้งค่าเสร็จแล้ว ระบบจะอนุญาตให้เข้าถึงได้ผ่าน 2 วิธีหลัก:

### วิธีที่ 1: ผ่าน URL Query (สะดวกสำหรับการทดสอบ)
พิมพ์ URL ใน Browser:
`https://your-domain.com/api/cron/unified?secret=ใส่รหัสลับที่นี่`

### วิธีที่ 2: ผ่าน Authorization Header (วิธีมาตรฐานของ Vercel)
Vercel จะส่ง HTTP Header มาพร้อมกับคำขอ:
`Authorization: Bearer <CRON_SECRET>`

---

## 🚨 ผลลัพธ์ที่คาดหวัง
- **ใส่รหัสถูกต้อง:** ระบบจะตอบกลับด้วย `200 OK` พร้อมรายละเอียดการรันงาน
- **รหัสผิด/ไม่ใส่รหัส:** ระบบจะตอบกลับด้วย `401 Unauthorized` พร้อมข้อความ Error
