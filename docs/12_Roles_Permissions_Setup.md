# คู่มือสิทธิ์การใช้งาน (Role & Permissions) - Multi-Tenant Architecture

เอกสารฉบับนี้อธิบายรายละเอียดสิทธิ์การใช้งานในระบบแยกสาขา (Multi-Tenant) สำหรับพนักงานในแต่ละระดับ

> **อัปเดตล่าสุด:** 4 มีนาคม 2026 (Enterprise v2.0 Ready)

## 1. TENANT ADMIN (ผู้ดูแลระบบสูงสุด)

- **นิยาม**: ผู้บริหารระดับสูง หรือผู้ดูแลระบบของแบรนด์/บริษัท
- **สิทธิ์การเข้าถึง**:
  - **การจัดการองค์กร**: สร้างสาขาใหม่ (Branch), แก้ไขข้อมูลสาขา และจัดการคำเชิญ (Invitations)
  - **การเงิน AI, AVM และคอมมิชชั่น 🆕**: เข้าถึงหน้า **AI Monitor** เพื่อตรวจสอบต้นทุน Token และจัดการการแบ่งสัดส่วนค่าคอมมิชชั่น (Advanced Commission Split) ทั่วทั้งบริษัท
  - **GTM & Analytics 🆕**: ตรวจสอบสถานะการทำงานของระบบติดตามพฤติกรรม (Google Tag Manager) และเหตุการณ์การติดต่อรายสาขา
  - **ภาพรวมข้อมูล**: มองเห็น Leads, Properties, Deals และสัญญาของ **ทุกสาขา** ภายใต้บริษัทตนเอง
  - **การจัดการสัญญา (Smart Contracts)**: สิทธิ์ในการอัปโหลดไฟล์แม่แบบ `.docx` มาตรฐานของบริษัท เพื่อให้ Agent ทั้งหมดใช้สร้างเอกสาร Dynamic
  - **ความปลอดภัย**: ดู Audit Logs ทั้งหมด และจัดการการโอนย้ายงานข้ามสาขา (Lead Referral)

## 2. BRANCH MANAGER (ผู้จัดการสาขา)

- **นิยาม**: หัวหน้าทีม หรือผู้ดูแลรับผิดชอบรายสาขา
- **สิทธิ์การเข้าถึง**:
  - **การจัดการสาขา**: มองเห็น จัดการ และตรวจสอบงานของ Agent ทุกคน **ภายในสาขาที่ตนเองสังกัด** เท่านั้น
  - **สถิติรายสาขา**: ดูหน้า Dashboard และ Executive Briefing เฉพาะข้อมูลของสาขาตนเอง
  - **ข้อจำกัด**: ไม่สามารถมองเห็นข้อมูลของสาขาอื่นที่ตนเองไม่มีชื่อเป็นสมาชิก และไม่สามารถแก้ไขการตั้งค่าระบบหลักได้

## 3. STAFF / AGENT (พนักงาน / ตัวแทน)

- **นิยาม**: พนักงานขาย หรือผู้ปฏิบัติงานทั่วไป
- **สิทธิ์การเข้าถึง**:
  - **การทำงานรายวัน**: สร้างและจัดการข้อมูล Leads, Properties และสัญญา (Contracts)
  - **การประเมินราคาอัจฉริยะ (AVM)**: สั่งรัน AI ประเมินราคา และพ่นแบบฟอร์ม Valuation PDF ออกมาเพื่อนำเสนอเนื้อหาให้ Lead
  - **การสร้างสัญญา (Document Gen)**: รันการสร้าง PDF จาก `.docx` ที่แอดมินอัปโหลดไว้ และส่ง E-Sign
  - **ข้อมูลส่วนตัว**: โดยพื้นฐานจะเห็นเฉพาะงานที่ได้รับมอบหมาย หรือข้อมูลภายในสาขาตามนโยบายความเป็นส่วนตัว (Isolation Mode)
  - **ขีดความสามารถ**: ใช้ระบบ AI ช่วยเขียนคอนเทนต์, โพสต์ลง Social Media และจัดการแชทใน Omni-channel Inbox

> 🚀 **อัปเดตสถานะโครงการล่าสุด (Late April 2026 - Enterprise Hardening Phase):**
> โปรเจคได้รับการยกระดับและจัดเตรียมความพร้อมขั้นสูงสุด (Production-Grade) โดยสิ่งที่ทำเสร็จสมบูรณ์เพิ่มเติมล่าสุดประกอบด้วย:
> - **🛡️ Native Proxy Type-Safety & Zero-Any:** ระบบหุ้มฐานข้อมูล (Runtime Proxy) ดักจับ CRUD Operations เพื่อบังคับใช้ `tenant_id` และป้องกันบั๊กข้ามสาขาอัตโนมัติ 100%
> - **⚡ Atomic Database & RPC Orchestrator:** ย้าย Business Logic ที่สำคัญเจาะจง (เช่น การย้ายบ้าน, ตัดสต็อก, เปลี่ยนดีล) ไปเป็น PostgreSQL RPC ป้องกันการสับเปลี่ยนข้อมูลผิดพลาด 
> - **💬 Enterprise Realtime Inbox:** ระบบแชท Omni-channel ขั้นเทพ รองรับ Infinite Scroll การกรองแยกหมวดหมู่ (Zero-latency) พร้อมสถานะการอ่าน/พิมพ์
> - **🔄 Inngest Background Jobs:** แยกงานที่หนักหัวเซิร์ฟเวอร์หลัก (AI Generation, การโพสต์โซเชียล) เข้ากระบวนการคิวอัตโนมัติ 
> - **🧱 Upstash Rate Limiting & Security:** ป้องกันสแปมและ Bot รัว API พร้อมระบบ Webhook Idempotency กันการยิงจาก Meta/Line ซ้ำซ้อน 
> - **🕰️ Property Audit Timeline:** ระบบ UI ตรวจดูประวัติการแก้ไขทุกฟิลด์ (Visual Diffing) พ่นชื่อผู้แก้ไขพร้อมปุ่มคลิก "กู้คืนเวอร์ชันเก่า" ได้ทันที
> - **🩺 Sentinel AI Human-in-the-Loop:** ระบบกรองความถูกต้องจากมนุษย์อีกชั้น ก่อนให้ผลลัพธ์ของ AI เผยแพร่จริง เพื่อความปลอดภัยต่อกฏหมาย
