# 🚀 VCC Asset Content Engine (TikTok SOP)

โฟลเดอร์นี้คือ **"สมองกลางระบบทำคอนเทนต์"** ของ VCC Asset ที่รวบรวมกฎเหล็ก, ฐานข้อมูลจริง, สไตล์การเล่าเรื่อง, และตารางงาน 30 วันทั้งหมดไว้ที่เดียว

---

## 📂 โครงสร้างโฟลเดอร์ (File Directory)

```text
content-engine/
├── README.md                      # (ไฟล์นี้) คู่มือระบบ & คำสั่งเรียกใช้ AI
├── 01_CONTENT_RULES.md            # กฎเหล็ก 7 ข้อ (SOP มาตรฐานการทำคลิป)
├── 02_FACT_SHEET.md               # ฐานข้อมูลราคาจริง & โครงการจริงในระบบ (ห้ามจกตา)
├── 03_CALENDAR_30DAYS.md          # ตารางคอนเทนต์ 30 วัน (5:3:2) พร้อมสถานะติดตาม
├── 04_POST_MORTEM_CHECKLIST.md    # บทเรียนจากคลิปจริง & เช็กลิสต์ตรวจสคริปต์
├── templates/
│   └── script-template.md         # แม่แบบเขียนสคริปต์รายวัน (Hook, Text, Demo, CTA)
└── scripts/
    ├── day-01.md                  # คลิปแรกที่ปล่อยไป + ผลวิเคราะห์
    ├── day-02.md                  # สคริปต์ Day 2 ฉบับแก้ไขถูกต้องตามกฎ 100%
    └── ...                        # สคริปต์วันต่อๆ ไป
```

## 🤖 วิธีสั่งงาน AI ในครั้งต่อไป (Prompt Shortcut)

เมื่อเปิดแชตใหม่ หรือต้องการคำปรึกษา ให้พิมพ์ประโยคง่ายๆ เหล่านี้ AI จะเปิดอ่านไฟล์ในโฟลเดอร์นี้และตอบได้ตรงเป๊ะทันที:

1. **ขอสคริปต์ประจำวัน:**  
   > *"ช่วยเขียนสคริปต์ Day 3 ให้หน่อย อิงตามกฎใน `content-engine`"*
2. **ตรวจสคริปต์ที่คิดเอง:**  
   > *"ตรวจสคริปต์นี้ให้หน่อยว่าผิดกฎใน `content-engine/01_CONTENT_RULES.md` จุดไหนบ้าง"*
3. **เช็คสต็อก/โครงการจริง:**  
   > *"งบ 20,000 มีโครงการไหนใน `02_FACT_SHEET.md` ที่เอามาทำ Hook ได้บ้าง"*
4. **ขอไอเดียต่อยอดคอมเมนต์:**  
   > *"มีคนเมนต์ถามว่า [...] ช่วยวางสคริปต์ตอบกลับตามสไตล์ content-engine ให้หน่อย"*
